## 5. 专项案例剖析

### 5.1 688012（中微公司）停牌强约束——验收报告 P0/P1 项
- 真实停牌区间：**2025-12-19 ~ 2025-12-31**（连续 9 个交易日成交额为 0，价格冻结）；
- 2026-01-05 为复牌后巨量日（成交额 84.7 亿元），若无强约束大概率误命中 AMO；
- 实测该日 `FACTOR_AMO=0`：停牌行落入 T-15 窗口，`SUM(IS_TRADING)<16` 否决——SQL 与 Python 双侧一致。**强约束有效。**

### 5.2 300360（顺网科技）精确平局案例——验证方法假警报
- Python float64 重算判 LABEL=1，CSV 存 0；
- Decimal 精确解剖：该股停牌冻结价导致 **MA5 在 T0 与 T-1 恰好完全相等（17.29 = 17.29）**，严格大于不成立；
- 结论：**CSV 正确**，系验证脚本浮点累加在精确平局上的 1e-15 幻影差异。Oracle NUMBER 十进制算术判得准确。

### 5.3 展示舍入与判定精度——设计内行为
- CSV 输出层 MA 为 `ROUND(...,3)`，而 ALIGN/ALL_UP/LABEL 用**全精度均线**判定；
- 与需求文档 §3.7「中间计算不舍入，仅展示层舍入」完全一致；
- 以 3 位小数反推标签时存在 |差|≤1e-3 的天然模糊区（占比 0.15%~2.09%），Decimal 全精度重算证明全部判定正确。

- `data → ver_20260819_091435` POSIX 原子切换正常，200 切片 + `dates_index.json` + `stock_200d_summary.json` + `meta.json` 齐全，索引合计行数 = 1,037,939；
