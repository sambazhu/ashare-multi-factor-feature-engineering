1️⃣ 因子全景：量级差三个数量级，稳定性差得离谱

200 天里每日命中数的均值、波动和总量差异极大——ma250_support 平均每天命中 502 只（占全市场 9.7%），是"宽网"；hl_5r 平均 42 只但单日能爆发到 682 只（波动率 191%），是"晴雨表"而不是"选股器"。HIGH_500 全程 0 命中：数据覆盖只有 512 个交易日，"上市超 500 天且突破 500 日高但未破覆盖期高"的窗口根本不存在。

💡 折线可以点图例开关。注意 2026-07-31 前后 hl_5r 单日冲到 682 只——当天正是 label≈19 的极度弱市技术性反弹日：弱市里"180 日回撤>25%"遍地都是，hl_5r 从底部反转精选退化成了弱市反弹大名单。绝对阈值在不同市场环境下含义完全不同。
🏷️ 因子其实分两类，但看板混在一起展示：5R / AMO / HL+AMO 是事件型（连续命中中位数 1 天，最长 3 天——"今天发生了"）；MA250 / MA377 支撑是状态型（中位 4-6 天，最长 57 天——"现在处于"）。状态型每天重复出现在列表里，稀释了事件型的信息密度。

2️⃣ 命中之后怎么样：前向超额收益

对每次因子命中，计算 T+1/5/10/20 日相对全市场等权基准的超额收益。核心读法：均值显著高于对照（+0.09%）的因子有正向预期；中位数主要反映"命中后短期内是继续冲还是回落"。

3️⃣ 同一个因子，牛市熊市两副面孔

按当日 LABEL 命中数（市场宽度代理）把 200 天分成强市 1/3 和弱市 1/3，分别统计 T+10 超额均值：

只在强市工作
5R（+0.72% → -1.21%）、HIGH_250（+0.97% → -2.75%）：趋势确认型，弱市全是假信号。
弱市反而更好
HIGH_ALL（+1.40% → +2.28%）：弱市里还能创新高的是真强势股，含金量更高。
什么环境都稳
LABEL（+0.91% / +0.65%）：唯一穿越强弱环境的标签。hl_amo 则什么环境都差。
🌐 对迭代的含义：用户在看板里解读任何因子信号都需要市场状态语境，但系统目前没有任何市场状态维度。这次样本还横跨了一次完整牛熊转换（LABEL 从 881 只跌到 69 只）——环境切换只发生一次，结论方向可信、数值不能外推。

6️⃣ 下一版本迭代建议

A. 新增 / 修改因子（按数据证据强度排序）

A1 证据最强
低流动性 / 低关注度因子：成交额处于自身 60 日低分位 + 价格稳定。ICIR -0.38 全场最强；现有 turnover 字段即可做时序分位版，真换手率需接流通股本（聚源 LC_SHARE 类表）。
A2
短期反转因子：ret10 < -X% 且未破位（仍在线上方）。IC -0.029，与现有动量类因子天然互补。
A3 零成本
行业新高扩散度（衍生指标）：各申万一级行业内 HIGH_ALL 命中占比 → 行业动量温度计。数据已有，纯展示层加工。
A4 修复
修 hl_amo / hl_5r 的环境淹没：给 dd180>25% 加市场状态门（当日宽度分位）或改相对分位阈值；或基于负超额证据直接降级为观察标签。
A5 重标定
AMO 阈值重标定：放量倍数 IC≈0，1.2×/1.8× 绝对阈值信息量不足，改用成交额 60 日 z-score 或分位数。
A6 阻塞项
落地 4R：建议 T0..T-3 四连红 + T-4 收绿、排除 5R/HL_5R（与 5R 对称），先以影子模式（计算不进主筛选）发布。另：HIGH_500 建议合并进 HIGH_ALL 展示或改用最大可得窗口。

B. 系统功能

B1 最高优先级
因子评价管道：每晚发布时对 T-20 及更早的命中补算前向收益，落成 factor_performance.json（滚动 T+1/5/10/20 超额中位 / 均值 / 胜率 / 半场对比）。这是防止"负超额因子上线半年才发现"的唯一机制，也是所有阈值调优的数据地基。本次的分析脚本可直接改造为原型。
B2
因子定义版本化：meta.json 加 factor_version 与阈值清单。没有它，日后无法区分"命中数变了是因子改了还是市场变了"。顺带解决 regression EXPECT 硬编码需手动同步的痛点（改为从发布版本快照派生）。
B3
发布健康度监控：08-20 源表回缩到 243 天被护栏正确拦截（实战验证有效），但只是静默拒绝——升级为失败通知 + "数据源覆盖天数趋势"面板，让源表异常可见。
B4
市场状态进数据契约：每日 label 命中数 / 上涨家数占比计算成 market_regime 字段写入切片，供前端叠加展示、供未来因子门控使用。

建议实施顺序： ① B1 + C1（工作量小、不碰因子定义，系统立刻从"信号列表"升级为"可评估的信号系统"） → ② B2（为阈值调整建立对照基础） → ③ A1-A3 影子模式上線跑两周对照 → ④ 用评价管道数据决定 A4 是修阈值还是降级。

📎 口径、限制与复现

  • 数据：线上版本 ver_20260819_091435 全部 200 个日切片， 股票-日、 只股票；前复权价格锚定同一发布批次，跨切片收益可直接计算。
  • 超额收益基准 = 全市场等权组合（含命中股自身）；对照组 = 全体股票-日随机抽样 15 万行。
  • 全部为样本内结论：200 天单窗口、一次牛熊转换、无交易成本假设。方向可信，数值不能外推，需滚动样本外验证。
  • Rank-IC = 每日截面 Spearman 秩相关（样本 ≥300 只），190 天平均；ICIR = IC 均值 / IC 标准差。
  • 复现：analysis/factor_deep_analysis.py（全景）、analysis/factor_control_ic.py（对照 + IC）、analysis/export_report_data.py + build_report.py（本报告）。
  • 报告日期 2026-08-20 · 由 200 日线上数据程序化生成，图表数字与数据完全一致。
